# 테스트 안내

저장소 루트에서 다음 명령을 실행하세요.

```sh
./scripts/build.sh
./scripts/test.sh
```

테스트는 별도의 UserDefaults 영역을 사용합니다. 사용 중인 앱의 규칙이나 설정은 변경하지 않습니다.

- Core 테스트에서는 타이머 경계, 시간 표시, 전원과 배터리 규칙, 설정 저장을 확인합니다.
- 통합 테스트에서는 모드 전환, 알림 내용, 규칙 우선순위, 시작 규칙의 중복 실행 방지를 확인합니다.
- 전원 이벤트 테스트는 고유한 테스트 알림과 가상 전원 상태를 사용합니다. 실제 시스템의 전원 알림을 조작하지 않습니다.
- IOKit 테스트는 잠자기 방지를 잠시 등록한 뒤 `pmset -g assertions`에서 해당 테스트 프로세스의 등록과 해제를 확인합니다.

테스트 도중 Buzz와 Doze 상태가 몇 초간 활성화됩니다. 테스트가 끝나면 해제됩니다.

자동 테스트만으로 실제 케이블 연결, 재부팅, 로그인, 화면 잠자기까지 검증할 수는 없습니다. 출시 전에는 실제 Mac에서도 해당 동작을 확인하세요.

## 자동 업데이트 검사

통합 테스트에서는 업데이트 후 모드와 타이머를 한 번만 복원하는지 확인합니다. 오래된 복원 정보, 다른 부팅의 정보, 설치에 실패해 이전 빌드가 다시 실행되는 경우에는 상태를 복원하지 않습니다.

실제 업데이트를 시험할 때는 현재 배포본보다 낮은 빌드 번호로 별도 앱을 만들 수 있습니다.

```sh
COFFEE_VERSION=1.0.99 COFFEE_BUILD=1099 ./scripts/build.sh
```

시험용 앱은 평소 쓰는 앱과 다른 폴더에 두고 실행하세요. 같은 설정 저장소를 사용하므로 동시에 실행하지 않는 편이 좋습니다. GitHub의 최신 정식 릴리스를 받아 설치한 뒤 버전, 모드, 타이머, 규칙이 유지되는지 확인하세요. 시험이 끝나면 기본 빌드를 다시 만드세요. 패키지 스크립트는 시험용 버전의 배포를 거부합니다.

## 언어 검사

테스트 스크립트는 영어와 한국어 번역의 누락 여부, 서식 인자의 순서와 자료형을 검사합니다. 통합 테스트는 영어, 한국어, 프랑스어 설정으로 각각 실행하며 프랑스어처럼 지원하지 않는 언어에서는 영어로 표시되는지 확인합니다. 언어 설정은 테스트 프로세스에만 적용됩니다.

실제 화면에서는 컨트롤, 자동 규칙, 설정, 메뉴 막대, 알림을 두 언어로 확인하세요. macOS의 앱별 언어 설정으로 Coffee Time의 언어만 바꿀 수 있으며, 변경 후에는 앱을 다시 실행해야 합니다.
