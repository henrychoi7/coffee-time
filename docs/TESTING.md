# 테스트 안내

저장소 루트에서 다음 명령을 실행하세요.

```sh
./scripts/build.sh
./scripts/test.sh
```

테스트는 별도의 UserDefaults 영역을 사용합니다. 사용 중인 앱의 규칙이나 설정은 변경하지 않습니다.

- Core 테스트에서는 타이머 경계, 시간 표시, 전원과 배터리 규칙, 설정 저장을 확인합니다.
- 통합 테스트에서는 모드 전환, 알림 내용, 규칙 우선순위, 시작 규칙의 중복 실행 방지를 확인합니다.
- 전원 이벤트 테스트는 고유한 테스트 알림과 가상 전원 상태를 사용합니다. 실제 시스템의 전원 알림을 조작하지 않습니다.
- IOKit 테스트는 잠자기 방지를 잠시 등록한 뒤 `pmset -g assertions`에서 해당 테스트 프로세스의 등록과 해제를 확인합니다.

테스트 도중 Buzz와 Doze 상태가 몇 초간 활성화됩니다. 테스트가 끝나면 해제됩니다.

자동 테스트만으로 실제 케이블 연결, 재부팅, 로그인, 화면 잠자기까지 검증할 수는 없습니다. 출시 전에는 실제 Mac에서도 해당 동작을 확인하세요.
