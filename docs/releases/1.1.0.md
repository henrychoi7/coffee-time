# Coffee Time 1.1.0

GitHub에서 내려받을 수 있는 첫 공개 릴리스입니다. Apple Silicon Mac과 macOS 13 이상에서 사용할 수 있습니다.

## 새로 달라진 점

- 앱에서 새 버전을 자동으로 확인하고 받아 설치합니다.
- 설치가 끝나면 앱을 다시 실행하고 사용 중이던 모드와 타이머를 이어갑니다.
- 메뉴 막대와 설정에서 업데이트를 직접 확인하거나 자동 업데이트를 끌 수 있습니다.
- 업데이트 파일과 목록의 서명을 확인한 뒤 설치합니다.

Buzz, Doze, Off 모드와 전환 타이머, 전원·배터리·다른 앱·시스템 시작 규칙, 알림, 미니 창, ⌘W로 창 닫기도 모두 포함돼 있습니다.

## 설치

처음 설치하거나 1.0.4 이하 버전을 사용한다면 아래 DMG를 받아 Applications 폴더로 옮기세요. 1.1.0부터는 이후 릴리스를 앱 안에서 자동으로 받을 수 있습니다. ZIP 파일은 자동 업데이트에도 사용됩니다.

현재 배포본은 Apple의 Developer ID 서명과 공증을 받지 않았습니다. 처음 실행할 때 macOS가 차단할 수 있으므로 이 저장소에서 직접 받은 파일인지 확인한 뒤 시스템 설정의 개인정보 보호 및 보안에서 실행을 허용해 주세요.
