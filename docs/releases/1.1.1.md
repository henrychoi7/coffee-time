## What’s new

- Coffee Time now uses English by default and Korean when selected in macOS language preferences
- Menus, settings, timers, notifications, errors, and update messages are available in both languages
- The README has a clearer download section, a quick feature overview, and expandable guides
- App bundles now include the MIT license alongside the existing third-party notices

You can choose a language just for Coffee Time in System Settings → General → Language & Region → Applications. Relaunch the app after changing its language.

Version 1.1.0 can install this update automatically. For a first installation, download the Apple Silicon DMG. The app requires macOS 13 or later and is not yet signed with an Apple Developer ID or notarized.

## 변경 사항

- 앱의 기본 언어를 영어로 바꾸고 macOS 언어 설정에 따라 한국어를 표시합니다.
- 메뉴, 설정, 타이머, 알림, 오류 메시지, 업데이트 안내에 두 언어를 적용했습니다.
- README의 다운로드 안내와 기능 요약을 정리하고 자세한 설명을 접어 볼 수 있게 했습니다.
- 기존 서드파티 고지와 함께 MIT 라이선스를 앱에 포함했습니다.

시스템 설정 → 일반 → 언어 및 지역 → 응용 프로그램에서 Coffee Time의 언어만 따로 지정할 수도 있습니다. 언어를 바꾼 뒤에는 앱을 다시 실행하세요.

1.1.0에서는 자동 업데이트로 설치할 수 있습니다. 처음 설치한다면 Apple Silicon용 DMG를 받으세요. macOS 13 이상이 필요하며 Apple의 Developer ID 서명과 공증은 아직 적용되지 않았습니다.
